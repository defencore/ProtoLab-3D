# Engineering library coverage

Compared with the user's analysis dated 2026-09-16. This is a model-library audit, not confirmation of compliance with every listed standard. The original catalog already contained 111 part packages; these were not added again.

The expansion added 54 independent packages and 189 variants: 177 parametric prototypes and 12 AMASS catalog models. Three additional wing variants use UIUC coordinates: Eppler E387, Selig S1223, and NACA 23012. See the machine-readable [package inventory](../data/library-expansion.json).

## Usage

New parts appear in the relevant library categories and subgroups. **Prototype examples** filters editable examples; they are not labeled as verified manufacturer products. Edit dimensions, bores, thicknesses, shafts, and other available parameters before exporting.

- **Envelope · assembly fit** provides simpler layout geometry. **Detailed · visible construction** appears only for families with additional geometry; it does not imply complete internal mechanisms.
- **Assembly** contains separate named components. **Exploded** separates them along Z for inspection, rather than defining a disassembly path or FreeCAD kinematic constraints.
- The O-ring, face groove, and radial groove tools are separate outputs. Position a cutter relative to the target and apply **Cut**. Groove width and depth are explicit inputs; squeeze is not calculated automatically.
- Housing models support checks of entered envelopes. Obtain the mounting dimensions of a purchased product from its drawing. A shape designation does not establish interchangeability.

## Sources and fidelity

Arbitrary new dimensions are not labeled as standard-verified. Package links explain construction families rather than verifying every parameter.

- [UIUC E387](https://m-selig.ae.illinois.edu/ads/coord_seligFmt/e387.dat), [S1223](https://m-selig.ae.illinois.edu/ads/coord_seligFmt/s1223.dat), [NACA 23012](https://m-selig.ae.illinois.edu/ads/coord_seligFmt/naca23012.dat): original coordinates are stored in `lifting-surface/lib/tabulated-profiles.json`. Each surface's X range is normalized from the shared leading extremity to its trailing end; the line joining these endpoints is subtracted from the ordinates to close the trailing edge. This explicitly changes NACA 23012's original finite trailing-edge thickness. Interpolation is linear; chord and span are user parameters.
- [Parker O-ring handbook](https://www.parker.com/content/dam/Parker-com/Literature/O-Ring-Division-Literature/ORD-5700.pdf): seal reference; automatic standards-based grooves are not implemented.
- [SDP/SI belts and pulleys](https://shop.sdp-si.com/products/synchronous-drive-belts-pulleys-cables/synchronous-drive-belts-pulleys.html): belt classification; generated teeth do not reproduce manufacturing profiles.
- [Festo cylinder families](https://www.festo.com/gb/en/c/products/actuators/pneumatic-cylinders-id_pim135): construction families; the new presets are not a Festo catalog.

## Verification

Reproducible checks: `tests/library-expansion.test.ts`, `tests/lifting-surface.test.ts`, and `tests/library-names.test.ts`. `scripts/verify-library-expansion.ts` prepares independently measured preview envelopes/volumes and macros for native verification through `scripts/verify-electronics.py`: closed positive solids, component collisions, preview/CAD agreement, independent movement, and STEP/FCStd reimport.

Geometry checks do not establish accuracy against unavailable drawings, strength, service life, or mechanism operation. This inventory **does not fulfill the entire analysis at manufacturing and kinematic-model fidelity**; remaining gaps are listed explicitly in the table.
