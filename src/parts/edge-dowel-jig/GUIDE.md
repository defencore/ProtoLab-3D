# Board edge dowel drilling jig

Centered or offset dowel rows with board-thickness cheeks and an end datum.

Find **WORKSHOP TOOLS → DRILLING JIGS → Board edge dowel drilling jig**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Measure board thickness, slide the U-shaped cheeks over its edge, press the stop against the board end and clamp. Drill blind holes using a depth collar. Keep the same face and end datum on both mating pieces; flip the fixture only when the required pattern is symmetric.

## Parameters and examples

Board thickness, Guide length, End stop to first dowel, Dowel count, Dowel pitch, Offset from board midplane, Guide bridge thickness, Registration cheek depth, Guide construction, Drill diameter, Bushing outside diameter, Bushing diametral seat allowance.

- Board12 / dowel6
- Board16 / dowel6
- Board18 / dowel8
- Board20 / dowel8
- Board25 / dowel10
- Two dowels / 64 mm pitch
