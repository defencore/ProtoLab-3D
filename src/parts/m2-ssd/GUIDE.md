# M.2 NVMe SSD installation reference

Generic module envelopes for mechanical planning with the Waveshare PCIe adapter. X is the length direction and +X points into the socket. The module is centered in XY; the PCB underside is Z=0 and the upper reference envelope is Z=3.5 mm. All dimensions are millimetres.

The format name supplies the nominal 22 mm width and 30/42/80 mm length. A 1 mm PCB, 2.5 mm component allowance and the end-notch construction are authored assumptions. There is no selected supplier, capacity, electrical performance or exact connector geometry. Choose and measure the actual NVMe SSD before fabrication. Heat sinks and attachment hardware are separate items.
