# Frame components

This module contains 152 physical source occurrences from SOURCE ONE V5, SOURCE TWO V0.1, SOURCE V V1 upgraded arms, SOURCE PODRACER V1, COMET Y6 and SOURCE ONE V4 X8. They share the **Multicopter frames** browse family. Filter by **Frame project** when choosing an individual component.

Shapes retain native BRep, fixed thicknesses and original curves. SOURCE V publishes closed shells; each is wrapped as a solid without sewing or contour repair. Browser tessellation has a 0.025 mm chord tolerance. Source component geometry is independent of assembly corrections and inspection poses.

SOURCE ONE assembly screw seating is corrected in the frame module; raw component shapes remain unchanged. Missing source hardware and printing routes are documented in the [frame guide](../multicopter-frame/GUIDE.md). Pinned revisions, authorship, GPL v3 and CERN-OHL-W v2 are in [lib/NOTICE.md](lib/NOTICE.md). Source CAD establishes geometry, not material quality or local flight qualification.

COMET parts retain individual source-file URLs and hashes. Its installed poses follow measured native mounting holes and the author build manual. Print inspection restores source orientation; do not print an installed sloping landing leg in that assembly pose. X8 stock parts use V4 interfaces and retain the source camera-cheek fit issues documented in the frame guide.
