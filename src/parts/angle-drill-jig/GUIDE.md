# Fixed-angle drilling shoe

Compact inclined guide with a flat clamping foot and a defined entry point on the workpiece.

Find **WORKSHOP TOOLS → DRILLING JIGS → Fixed-angle drilling shoe**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Put the flat foot on the workpiece, locate the defined entry point, clamp, and use an aligned hand drill. For a vertical drill press, tilt the clamped workpiece/fixture to align the guide with the spindle; never force a vertical bit into an inclined guide. The angle is printed into each shoe; measure the actual result before repeating critical holes.

## Parameters and examples

Drill tilt from surface normal, Clamping foot length, Clamping foot width, Inclined guide length, Foot thickness, Guide construction, Drill diameter, Bushing outside diameter, Bushing diametral seat allowance.

- Normal drilling / 0 degrees
- Tilt15
- Tilt22.5
- Tilt30

## Manufacture and limits

The FreeCAD tree contains independent physical components; inspection separation does not change their definitions. Select a body for individual STEP/STL export. Purchased elements, where present, are nominal procurement envelopes; select actual parts and verify their interfaces. Steel bushings require a qualified fit and retention method. Printed pilot guides are for marking and occasional use. Check actual drill passage and chip clearance before repeating holes.

Clamp both fixture and workpiece, set the drilling/cutting depth separately, and verify the first piece before repeating. Measure datum faces, printed fits and actual tool sizes. No machine accuracy, load capacity or production qualification is implied by a valid solid.
