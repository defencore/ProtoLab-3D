# Chain-drill and slot layout kit

Paired pilot-drilling and finished-profile masks for making slots with a drill and files.

Find **WORKSHOP TOOLS → ROUTING & PROFILE TEMPLATES → Chain-drill and slot layout kit**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Register and clamp the pilot mask, drill pilot holes, remove it and enlarge each hole separately. Remove the remaining webs with a suitable saw/file. Use the matching outline mask to scribe and inspect the final profile, and remove the polymer mask while filing. Positive web spacing avoids deliberately overlapping full-size drilled holes.

## Parameters and examples

Finished slot length, Finished slot width, Enlargement drill diameter, Template thickness, Clamping border, Guide construction, Drill diameter, Bushing outside diameter, Bushing diametral seat allowance.

## Manufacture and limits

The FreeCAD tree contains independent physical components; inspection separation does not change their definitions. Select a body for individual STEP/STL export. Purchased elements, where present, are nominal procurement envelopes; select actual parts and verify their interfaces. Steel bushings require a qualified fit and retention method. Printed pilot guides are for marking and occasional use. Check actual drill passage and chip clearance before repeating holes.

Clamp both fixture and workpiece, set the drilling/cutting depth separately, and verify the first piece before repeating. Measure datum faces, printed fits and actual tool sizes. No machine accuracy, load capacity or production qualification is implied by a valid solid.
