# V-block cross-drilling jig

End-referenced cross holes in round shafts and tubes using a drill press or hand drill.

Find **WORKSHOP TOOLS → DRILLING JIGS → V-block cross-drilling jig**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Slide the rod against the end stop, seat it in the V, and clamp both stock and fixture in a vise. Drill through the top guides. This version references one measured stock OD; changing OD changes its bridge height. Use a depth stop when only one tube wall should be drilled.

## Parameters and examples

Round stock outside diameter, Fixture length, End stop to first hole, Hole count along shaft, Hole pitch, Top guide thickness, Guide construction, Drill diameter, Bushing outside diameter, Bushing diametral seat allowance.

- Rod OD8 / one cross hole
- Rod OD12 / one cross hole
- Rod OD20 / two holes
- Tube OD30 / two holes
- Tube OD50 / one hole
- Rod OD20 / three holes

## Manufacture and limits

The FreeCAD tree contains independent physical components; inspection separation does not change their definitions. Select a body for individual STEP/STL export. Purchased elements, where present, are nominal procurement envelopes; select actual parts and verify their interfaces. Steel bushings require a qualified fit and retention method. Printed pilot guides are for marking and occasional use. Check actual drill passage and chip clearance before repeating holes.

Clamp both fixture and workpiece, set the drilling/cutting depth separately, and verify the first piece before repeating. Measure datum faces, printed fits and actual tool sizes. No machine accuracy, load capacity or production qualification is implied by a valid solid.
