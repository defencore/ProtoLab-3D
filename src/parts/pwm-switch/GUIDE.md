# PWM electronic switch

Selected 17x13x10 mm switch with rounded sleeve, terminal exits and signal connection.

Body envelope: 17 x13 x10 mm. Loose leads excluded.

solids. The recovery assembly uses this same library geometry. Mounting and
electrical connections must be verified on the purchased hardware.
