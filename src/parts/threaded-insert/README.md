# Threaded insert and rivet nut

Heat-set, flanged insert, rivet nut and self-clinching nut forms.

Find **FASTENERS & THREADS → INSERTS & RIVETS → Threaded insert and rivet nut**.

## Variants

- Heat-set insert · M3
- Press-fit insert · M4
- Rivet nut · M6
- Self-clinching nut · M3

## Controls

Insert form; Body diameter; Thread nominal diameter; Body length; Flange diameter; Model detail.

## Scope

Rivet nut shown before setting; heat-set ribs are illustrative, not a thermal installation specification. Dimensions are editable prototype choices, not source-certified product dimensions or a manufacturing drawing. Threads are smooth nominal envelopes unless explicitly stated. No load, pressure or service-life rating is implied.

Separate named components are exported to FreeCAD; the exploded state separates them along Z. The preview and native export share the same shape recipe. This is an independent, editable package.
