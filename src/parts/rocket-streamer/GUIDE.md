# Rocket recovery streamer

One purchased strip represented as an unfolded rectangular sheet. The family corresponds to the Streamer recovery component in [OpenRocket's official overview](https://openrocket.readthedocs.io/en/latest/user_guide/basic_rocket_design.html#mass-components), reviewed 2026-10-25. The source establishes the component type only; all preset dimensions are authored examples.

The origin is the center of the sheet. X is unfolded length, Y is width, and Z is reference thickness. Preview, STL and FreeCAD describe one closed rectangular solid with the same nominal envelope. Choose separate project occurrences for multiple strips.

Select the actual product, material, dimensions and retention before procurement. The reference does not model folds, seams, flutter, aerodynamic drag, packing volume, temperature exposure or descent speed. Verify the strip and harness attachment on the actual recovery system.
