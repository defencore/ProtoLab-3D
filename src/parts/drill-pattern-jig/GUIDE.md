# Flange and grid drilling jig

Referenced guide plate for bolt circles, rows, rectangular patterns and flanges.

Find **WORKSHOP TOOLS → DRILLING JIGS → Flange and grid drilling jig**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Clamp the two underside fences against perpendicular workpiece edges. Spot all positions, drill through a steel bushing or transfer pilot marks, and remove the fixture before enlarging or tapping holes. For a round flange, first locate its center relative to the two edge datums using a sacrificial carrier or stops; this plate does not self-center on an arbitrary circular blank.

## Parameters and examples

Hole pattern, Bolt circle diameter, Circular / row hole count, Grid rows, Grid columns, Horizontal pitch, Vertical pitch, Guide plate thickness, Clamp border, Datum fence depth, Guide construction, Drill diameter, Bushing outside diameter, Bushing diametral seat allowance.

- Flange PCD40 / 4 holes
- Flange PCD60 / 6 holes
- Flange PCD80 / 8 holes
- Flange PCD100 / 12 holes
- Grid 3 x 2 / pitch32
- Row / 6 holes at 20 mm

## Manufacture and limits

The FreeCAD tree contains independent physical components; inspection separation does not change their definitions. Select a body for individual STEP/STL export. Purchased elements, where present, are nominal procurement envelopes; select actual parts and verify their interfaces. Steel bushings require a qualified fit and retention method. Printed pilot guides are for marking and occasional use. Check actual drill passage and chip clearance before repeating holes.

Clamp both fixture and workpiece, set the drilling/cutting depth separately, and verify the first piece before repeating. Measure datum faces, printed fits and actual tool sizes. No machine accuracy, load capacity or production qualification is implied by a valid solid.
