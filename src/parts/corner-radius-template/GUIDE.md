# Corner radius scribing template

Two-edge corner registration for marking, sanding and checking external radii.

Find **WORKSHOP TOOLS → ROUTING & PROFILE TEMPLATES → Corner radius scribing template**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Seat both underside stops against the original perpendicular corner edges. Clamp, scribe the profile, remove the template and cut/sand/file to the line. Refit as a comparison gauge. This is an exact-size profile, not a compensated router guide or a certified radius gauge.

## Parameters and examples

Finished external corner radius, Template side length, Template thickness, Underside edge-fence depth.
