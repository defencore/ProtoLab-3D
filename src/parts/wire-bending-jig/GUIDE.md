# Pin and mandrel wire-bending jig

Simple loop and U-bend tooling with replaceable metal mandrels and a drilled mounting plate.

Find **WORKSHOP TOOLS → BENDING & ASSEMBLY JIGS → Pin and mandrel wire-bending jig**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Make the base from metal plate using the model as a drilling layout, secure mandrels and pins mechanically from beneath, and clamp the plate to a bench. Bend suitable soft wire by hand around the mandrels. Test springback and length allowance on a sample. A printed base is only a layout/light-duty prototype; it is not qualified tooling for steel strip or high-force bending.

## Manufacture and limits

The FreeCAD tree contains independent physical components; inspection separation does not change their definitions. Select a body for individual STEP/STL export. Purchased elements, where present, are nominal procurement envelopes; select actual parts and verify their interfaces.

Clamp both fixture and workpiece, set the drilling/cutting depth separately, and verify the first piece before repeating. Measure datum faces, printed fits and actual tool sizes. No machine accuracy, load capacity or production qualification is implied by a valid solid.
