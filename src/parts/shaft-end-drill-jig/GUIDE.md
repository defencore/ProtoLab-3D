# Shaft end-centering drill guide

Slip-on end stop for centered axial pilot holes in rods and small tube end plugs.

Find **WORKSHOP TOOLS → DRILLING JIGS → Shaft end-centering drill guide**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

Use on a measured round shaft. Insert its end until it meets the cap shoulder, clamp the shaft and sleeve, and spot-drill through the axial guide. Do not use a loose fit as a precision center. The fixture is for stationary drilling, not for a rotating lathe spindle.

## Parameters and examples

Shaft diameter, Sleeve engagement length, End plate thickness, Shaft diametral clearance, Sleeve radial wall, Guide construction, Drill diameter, Bushing outside diameter, Bushing diametral seat allowance.

- Shaft OD10 / drill2
- Shaft OD12 / drill3
- Shaft OD16 / drill4
- Shaft OD20 / drill5
- Shaft OD30 / drill6

## Manufacture and limits

The FreeCAD tree contains independent physical components; inspection separation does not change their definitions. Select a body for individual STEP/STL export. Purchased elements, where present, are nominal procurement envelopes; select actual parts and verify their interfaces. Steel bushings require a qualified fit and retention method. Printed pilot guides are for marking and occasional use. Check actual drill passage and chip clearance before repeating holes.

Clamp both fixture and workpiece, set the drilling/cutting depth separately, and verify the first piece before repeating. Measure datum faces, printed fits and actual tool sizes. No machine accuracy, load capacity or production qualification is implied by a valid solid.
