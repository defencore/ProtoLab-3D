# Configured supplier component

An opaque supplier configuration separates procurement identity from display solids. The assembly specification counts the complete ordered product once, including products whose preview shows races, balls, caps, coils or housings.

The project must specify its real order designation, manufacturer, supplier evidence and verified interfaces. The local structured recipe is an installation model; it neither guarantees commercial availability nor certifies functional geometry. Unidentified or unverified products retain documentation and engineering review requirements.

This family shares the recipe renderer with `manufactured-detail`. Its configuration describes one supplier installation recipe in the default state. The manufacturing form and dimensional template controls belong to the manufactured detail family. Product identity uses the configured supplier installation recipe.
