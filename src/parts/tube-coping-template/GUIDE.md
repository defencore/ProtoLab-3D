# Tube fishmouth scribing sleeve

Geometric saddle intersection for marking round-tube joints before hand cutting and fitting.

Find **WORKSHOP TOOLS → ROUTING & PROFILE TEMPLATES → Tube fishmouth scribing sleeve**. Select a starting example, then edit dimensions. Units are millimetres.

## Setup and operation

This sleeve marks the intersection of two outside cylindrical surfaces. Set its axial position from a separate length/layout datum, align its angular phase, clamp lightly and scribe the top edge. Remove before cutting and hand-fit the joint. The profile is a sampled geometric layout, not a saw guide, a weld procedure or a finished-length end stop.

## Parameters and examples

Tube being trimmed OD, Mating tube OD, Angle between tube axes, Sleeve diametral clearance, Sleeve radial wall, Minimum scribing edge height, Angular phase.

- Tube25 to tube25 / 90 degrees
- Tube25 to tube40 / 90 degrees
- Tube25 to tube40 / 45 degrees
- Tube32 to tube50 / 60 degrees
- Tube40 to tube60 / 90 degrees
- Tube50 to tube76 / 45 degrees
