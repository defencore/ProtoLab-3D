# Configured recovery component

The structured local feature recipe defines the reusable library configuration. Installation pose is stored separately in the assembly occurrence. Source contours, fused fabrication layers and printed thread fits retain their detailed geometry. Native supplier servo and PCB internals cannot be inserted into a fabricated-detail recipe.

Before release, attach the applicable material, blank, qualified manufacturing route and drawing, or the actual supplier procurement record. Closed CAD geometry is not a manufacturing qualification.
