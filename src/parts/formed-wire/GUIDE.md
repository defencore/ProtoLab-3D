# Configured formed wire

The local centreline and round-wire diameter define one reusable physical detail. The preview uses a capped wire mesh and the FreeCAD recipe lofts transported circular sections along the same centreline.

This is an authored fabrication definition, not a purchased spring catalog. A project must record wire grade, free geometry, manufacturing route, heat treatment, tolerances and inspection. When an assembly supplies a posed tension-spring path, its spring rate, preload, unloaded geometry and fatigue capability remain unresolved engineering requirements.

Centreline JSON accepts only finite coordinate triples. It contains geometry data, never executable code. Self-intersection and adjacent duplicate points are rejected.
